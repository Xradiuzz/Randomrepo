# NEON//RELAY

A self-contained, mobile-first neon survival arcade built with vanilla HTML, CSS and JavaScript. No frameworks, packages, server, or build step required.

## Run locally
Open `index.html` in a modern browser.

## Controls
- **Desktop:** WASD / arrow keys to move, Space or Shift to dash, P / Esc to pause.
- **Touch:** left virtual stick to move, right button to dash.
- Weapons automatically target the nearest hostile signal.

## Gameplay
Survive escalating waves, eliminate drones, collect energy fragments, level up and choose upgrades. Your best score is stored locally in the browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push to `main`. The included workflow publishes the game automatically.
4. Open the URL shown in **Settings → Pages**.

Everything runs client-side. Progress is stored in local browser storage.
